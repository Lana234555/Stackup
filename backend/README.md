# Кабінет заявок Stackup: налаштування

Бриф (`brief.html`) надсилає заявки в Google Apps Script. Скрипт працює безкоштовно на вашому Google-акаунті:
- кладе кожну заявку в окрему папку на Google Drive (`Stackup — Брифи`): `brief.html`, `brief.json` і всі файли клієнта;
- додає рядок у таблицю «Stackup — Заявки»;
- надсилає вам лист про нову заявку.

Кабінет (`admin.html`) показує заявки в стилі Stackup. У ньому можна змінювати статус, писати нотатки й відкривати файли.

## Один раз, ~5 хвилин

1. Відкрийте https://script.google.com і натисніть **New project** (Новий проєкт).
2. Видаліть вміст `Code.gs` і вставте туди весь файл `backend/Code.gs`. Збережіть (💾).
3. Угорі оберіть функцію **setup** і натисніть **Run** (Виконати). Google попросить дозволи: **Review permissions → ваш акаунт → Advanced → Go to project → Allow**.
   У журналі (Execution log) з'явиться рядок `Ваш ключ для кабінету: …`. Збережіть цей ключ, він знадобиться для входу в кабінет.
4. Натисніть **Deploy → New deployment**, у шестерні оберіть тип **Web app** і вкажіть:
   - *Execute as:* **Me**
   - *Who has access:* **Anyone**

   Натисніть **Deploy** і скопіюйте **Web app URL** (закінчується на `/exec`).
5. Вставте цей URL у `config.js` у поле `endpoint` (або надішліть його мені, і я вставлю сама).
6. За бажанням: **Project Settings → Script properties** → додайте `ADMIN_URL` = `https://stackup.studio/admin.html`. Тоді в листі про заявку буде кнопка «Відкрити в кабінеті». `NOTIFY_EMAIL` — пошта для сповіщень (за замовчуванням ваша).

Кабінет: `https://stackup.studio/admin.html`, вхід за ключем з кроку 3.

## Якщо змінюєте Code.gs
Після змін: **Deploy → Manage deployments → ✎ → Version: New version → Deploy**. URL при цьому не змінюється.

## Обмеження
- До 25 МБ на файл. Більші файли клієнт передає посиланням (є поле в брифі).
- Ключ кабінету дає доступ до списку заявок. Не публікуйте його; щоб змінити ключ, видаліть властивість `ADMIN_KEY` і знову запустіть `setup`.
