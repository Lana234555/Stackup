# Тести безпеки CRM

Запускають `backend/Code.gs` на імітації Google Apps Script (без вашого акаунта).

- `node tests/security.test.js` — 52 сценарії бекенду: вхід, код із листа, блокування підбору, сесії, довірені пристрої, захист брифу.
- `node tests/login.e2e.js` — 17 сценаріїв у справжньому браузері (потрібен Playwright): вхід, XSS у заявках, вихід, автовихід, iframe, CSP.
